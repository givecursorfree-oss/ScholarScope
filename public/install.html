Download ZIP · Load unpacked

Not listed on the Chrome Web Store yet. Use Load unpacked below. When a listing is live, set SCHOLARSCOPE_CHROME_STORE_URL so an official store badge can appear.

Chrome

  1. Download ScholarScope-extension.zip
  2. Unzip it (you get one folder)
  3. Open chrome://extensions and turn on Developer mode
  4. Click Load unpacked → select that unzipped folder
  5. Pin ScholarScope, then visit a journal page on SciMAGO or a publisher site

Microsoft Edge

  1. Download the same ZIP
  2. Unzip it
  3. Open edge://extensions and turn on Developer mode
  4. Click Load unpacked → select that unzipped folder

Browsers block installing custom .crx / .extension files from websites. A ZIP package is the official sideload format. For one-click install and automatic updates, publish the same package to the Chrome Web Store (or Edge Add-ons). See also the privacy policy.
