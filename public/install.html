Chrome

  1. Download ScholarScope-extension.zip
  2. Unzip it (you get one folder)
  3. Open chrome://extensions and turn on Developer mode
  4. Click Load unpacked → select that unzipped folder

Microsoft Edge

  1. Download the same ZIP
  2. Unzip it
  3. Open edge://extensions and turn on Developer mode
  4. Click Load unpacked → select that unzipped folder

Browsers block installing custom .crx / .extension files from websites. A ZIP package is the official format. For true one-click install and automatic updates, publish the same ZIP to the Chrome Web Store (or Edge Add-ons).
